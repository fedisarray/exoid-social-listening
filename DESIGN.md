# Analyst workspace

A property comparison workspace with clear group boundaries and explicit reporting dates.
Palette: ink #172d3b, blue #215e88, surface #ffffff, canvas #f3f6f8, muted #687b89, border #dce4e9; map through semantic tokens.
Typography: system sans for controls and body, Georgia for restrained page titles. Data uses tabular numbers.
Layout: narrow dark blue navigation rail on desktop; compact header on mobile. Wide content aligned left, property rows rather than decorative KPI cards. One primary action per form. Quiet rounded controls from shadcn.
Behavior: visible unsaved/saving/saved/conflict states, preserved drafts, no fabricated charts. All layouts work at 360px and keyboard focus stays visible.
